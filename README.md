## 🚀 Featured projects

### 🎓 Academic Social Platform · *team of 5*

A full-stack social network for students, powered by a **multi-agent AI assistant**.

- 💬 Posts, comments, **real-time messaging (WebSocket)** and **OAuth2/JWT** authentication
- 🪪 **OCR-based identity verification**: students sign in after their student card is verified
- 🤖 **Multi-agent AI assistant** (LangGraph, Groq, llama-3.3-70b):
  - 🗄️ **SQL agent** over platform data
  - 📚 **RAG agent** over PDF/DOCX files (PGVector)
  - 🔎 **Web search agent** (Tavily)
  - 🧠 **User-preference memory agent**
- 🧭 **Recommendation engine**: an asynchronous scoring system that prioritizes courses, news and academic discussions in each student's feed
- 📰 **Auto-generated weekly digest** of the most discussed topics, with **Redis caching** of LLM responses
- 🐳 **Docker Compose** deployment
